# Principal Portal

A read-only dashboard to view attendance status and monthly records.

---

## Files

- `principal.html` — the dashboard
- `README.md` — this file

---

## How to Use

1. Open the portal link.
2. Enter the **Principal code** (given to you by the school coordinator).
3. **Today's view** shows each class:
   - **Taken** (green) or **Pending** (red)
   - Teacher name, time, present/absent count
4. **Records** section:
   - Select **Year → Month → Class**
   - Tap **Show** to view the monthly sheet
   - Tap **Open in Google Sheets** for the raw file
5. Students below **75%** attendance are shown in **red**.

---

## Notes

- This portal is **read-only** — no edits possible.
- Your principal code is saved on your device after first login.
- The session stays logged in until you clear browser data.

---

## Problems?

| Issue | Fix |
|-------|-----|
| Wrong code | Check with the coordinator — principal code doesn't rotate |
| No records shown | Class may not have attendance for that month yet |
| Blank page | Check internet connection |

Contact your **school coordinator** for help.
